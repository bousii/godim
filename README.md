# Godim


[Neovim](https://neovim.io/) is a fork of Vim to allow greater extensibility
and integration.
Godim is a Neovim plugin for the Godot Game Engine. This plugin does not
just emulate the Vim program, however. Similar to [vscode-neovim](https://github.com/vscode-neovim/vscode-neovim),
this plugin uses a fully embedded Neovim instance. More to come as this gets developed!
